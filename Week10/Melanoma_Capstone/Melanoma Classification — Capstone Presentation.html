THE PROBLEM

Can a CNN distinguish a benign lesion from a malignant one?

Melanoma is one of the most dangerous forms of skin cancer, but early visual detection is possible from dermoscopic images. The challenge is that benign and malignant lesions can look similar even to trained observers — making automated classification a meaningful and non-trivial task.

METHODOLOGY

Three approaches. One winner.

Three CNN configurations were trained and compared on the same dataset using the same evaluation protocol.

Sigmoid
1
CNN from Scratch — baseline without augmentation. Overfitting appeared after Epoch 8; training accuracy continued climbing while validation plateaued.
2
CNN + Data Augmentation — same architecture with random flips, rotations, zoom, and brightness. The training/validation gap narrowed. Selected model.
3
MobileNetV2 (frozen) — ImageNet pretrained weights, frozen base, new classification head. Lower test performance in this configuration; fine-tuning identified as future work.

1
Data augmentation reduced overfitting: the training/validation accuracy gap was smaller with augmentation than in the scratch baseline — evidence the model learned patterns, not image positions.
2
Confidence is not certainty: borderline cases (e.g., confidence ~61%) reflect genuine ambiguity in the lesion's visual appearance — the model's uncertainty mirrors the difficulty.
3
MobileNetV2 limitation: frozen pretrained layers couldn't adapt to dermoscopic image characteristics. Fine-tuning the deeper layers is the identified next step.

LIMITATIONS & FUTURE WORK

Honest assessment and next steps

Current Limitations

  • Evaluated on one dataset — generalization to other populations is unverified
  • Images resized to 112×112 — some fine-grained detail is lost
  • MobileNetV2 tested with frozen layers only — fine-tuning not evaluated
  • 3 test images for live verification — not a statistical sample
  • No clinical validation — not a diagnostic tool

Identified Next Steps

  • Fine-tune pretrained MobileNetV2 layers on melanoma data
  • Evaluate at higher resolutions (224×224)
  • Add SHAP / Grad-CAM for visual explainability
  • Expand test coverage with automated testing
  • Add confidence threshold UI warning for borderline cases
  • Evaluate on an external validation dataset
